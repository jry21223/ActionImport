# 01: 重复接入时快速跳过已导入素材

**What to build:** 相机再次接入时，已经导入完成、且来源和归档都没有变化的文件，不再重新读取整张卡和整个归档做 SHA-256，而是凭清单记录快速判定为“已有”。用户仍可以手动发起一次“完整核对”，重新读取全部素材。新复制的文件，校验时读的是磁盘上的数据，而不是刚写入的系统缓存。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

背景：现在只要清单里有记录或目标已存在，就会对来源和目标各算一遍哈希。卡上有 100GB 旧素材时，每次接入都要读约 200GB，自动导入因此显得很慢。

- [ ] 清单记录来源修改时间、目标修改时间与目标文件身份；来源路径、大小、修改时间都一致，且归档文件仍是同一个未改动的普通文件时，跳过且不读取内容
- [ ] 任何一项不一致（包括旧版清单缺少新字段）时，回到现有的完整核对路径；损坏归档仍会被发现并另存新副本，不覆盖
- [ ] 提供“完整核对”入口（菜单栏右键与命令行），强制对所有文件走完整核对
- [ ] 复制后的读回校验绕过页缓存
- [ ] fixture 检查覆盖：快速跳过不读取来源内容、来源变化、归档被改写、旧版清单、完整核对模式
- [ ] 现有 12 项检查全部通过

不做：清单批量写入。逐文件写清单是 GLOSSARY 中“导入完成 = 已记录完成状态”的一部分，几百个文件的 JSON 开销可以忽略。
